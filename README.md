# Saúde 4.0 - Predição de Risco Cardiovascular (Care Plus)

Este projeto utiliza **Regressão Logística** para prever o risco cardiovascular alto com base em dados de dispositivos wearables.

## Objetivo
Construir um modelo preditivo para triagem proativa de pacientes, focando em métricas de **Recall** para garantir a segurança clínica.

## Principais Resultados
- [cite_start]**Probabilidade do Caso de Teste:** 99.94%[cite: 99, 157].
- [cite_start]**ROC AUC:** 1.00[cite: 110, 143].
- [cite_start]**Métrica Foco:** Recall (Minimização de Falsos Negativos)[cite: 106, 151].

## Tecnologias Utilizadas
- Python (Pandas, NumPy)
- Scikit-learn (LogisticRegression, StandardScaler)
- Matplotlib & Seaborn (Visualização de Dados)
